+ Como publicar um projeto

Todo mundo pode publicar. Edite o arquivo projetos.json na raiz do site, adicione um objeto ao array projects e abra um pull request no GitHub:

{
  "title": "Meu projeto",
  "description": "Uma frase curta explicando o que ele faz.",
  "url": "https://exemplo.com",
  "tags": ["python", "automação"],
  "status": "ativo",
  "featured": true,
  "accent": "purple",
  "icon": "🚀"
}
  • status: ativo, em breve ou arquivado.
  • accent: green ou purple.
  • featured: true para aparecer também na página inicial.
  • icon: um emoji ou o caminho de uma imagem (ex.: assets/meu-icone.png).
